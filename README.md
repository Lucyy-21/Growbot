# GrowBot 🌱

A WhatsApp farming assistant for Nigerian smallholder farmers.

## Features
- 🌤️ Real-time weather data via OpenWeatherMap API
- 🌾 Crop advice for 12 crops (tip, soil, spacing)
- 📱 WhatsApp integration via Twilio
- 🗣️ Weather-based planting recommendations

## Tech Stack
- Python + Flask
- Twilio WhatsApp Sandbox
- OpenWeatherMap API
- ngrok for local development

## Setup
1. Clone the repo
2. Create .env with OPENWEATHER_API_KEY=your_key
3. Run python app.py
4. Run 
grok http 5000
5. Configure Twilio webhook to your ngrok URL

## Available Crops
beans, cassava, cocoyam, groundnut, maize, millet, okra, plantain, rice, sorghum, tomato, yam
